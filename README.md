# LJT-Homepage

Personal academic homepage for **Junteng Liu**, built with Jekyll using the Academic Pages theme.

## Content

- **About:** personal details, academic background, research experience, skills, publications, and contact information.
- **Publications:** detailed records of Junteng Liu's publications.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site is served at `http://localhost:4000/LJT-Homepage/`.
